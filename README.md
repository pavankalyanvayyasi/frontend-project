# Tech.Care Healthcare Dashboard

Frontend Skills Test – Coalition Technologies

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Chart.js
- REST API Integration

## How to Run

1. Extract the ZIP file.
2. Open the project folder in VS Code.
3. Open a terminal inside the folder containing `index.html`.
4. Run:

   `python -m http.server 5500`

   On Windows, `py -m http.server 5500` can also be used.

5. Open Chrome and visit:

   `http://localhost:5500/`

## API Integration

The dashboard fetches patient information from the provided Coalition Technologies API and displays Jessica Taylor's healthcare information.

An internet connection is required to fetch the API data and load Chart.js from the CDN.
